# Security policy

OI is an experimental research prototype, not a production security or decision-authority system. Do not use it to authorize consequential real-world actions without independent review.

## Reporting
Please do not post exploitable vulnerabilities, personal information, credentials, or wallet secrets in public issues. Contact the repository owner privately through an established private channel to arrange secure disclosure. Do not send secrets until a secure channel is agreed.

## Publication gate
Before changing visibility: review all Git history, branches, tags, workflow logs, artifacts, configuration, dependency licenses, personal data, and any embedded credentials or keys. Rotate and revoke any exposed secrets; removing a file from the latest commit alone does not remove historical exposure. Resolve or document known test and security limitations.
