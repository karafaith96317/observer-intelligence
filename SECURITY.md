# Security Policy

Do not open a public issue for a suspected vulnerability, exposed credential, private data leak, or biometric-data concern.

Report the issue privately to the repository owner. Include the affected file or component, reproduction details, and potential impact. Do not include real credentials, raw biometric records, private keys, or personal data in the report.

This project is research-stage software. It must not be used as the sole basis for identity authentication, medical decisions, safety-critical control, or irreversible autonomous action.
