# Public release gate (not yet approved)

- [ ] Review full Git history, branches, tags, Actions logs and artifacts for secrets and personal data.
- [ ] Verify ownership and license compatibility of every third-party dependency, excerpt, dataset and image.
- [ ] Confirm whether any patent filing or confidential IP review is needed before disclosure.
- [ ] Owner approves final software license and its scope; update LICENSE and CITATION.cff together.
- [ ] Validate reproducible tests and clearly document experimental limits and outstanding PR blockers.
- [ ] Review security and contribution policies and verify contact channel.
- [ ] Owner explicitly approves repository visibility change.

This checklist is not evidence that the checks have been completed.
