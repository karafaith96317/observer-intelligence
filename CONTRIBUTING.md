# Contributing

This is currently a private, originator-led research project.

Before contributing, collaborators must agree in writing on background IP, confidentiality, repository ownership, publication rights, attribution, and treatment of newly created IP. Do not submit confidential third-party information, personal data, biometric data, production credentials, or unlicensed material.

A contribution is not accepted merely because it appears in an issue, message, branch, or pull request. Acceptance and applicable rights must be confirmed by the repository owner in writing.
