## Strongest initial positioning

OI should not be presented as a complete Space Academy architecture. The strongest proposition is narrower:

> A candidate experiential-training and research pilot for testing provenance-preserving, adversarially robust, authority-bounded AI-assisted decision processes in high-stakes space scenarios.

## What must be demonstrated before making performance claims

1. Freeze a baseline comparator and evaluation protocol.
2. Define scenario fixtures and ground truth where possible.
3. Run repeated trials under majority error, dependent/Sybil evidence, replay, scope escalation, stale evidence, measurement degradation, and contradictory telemetry.
4. Report failures as well as successes.
5. Separate mechanism tests from comparative outcome claims.
6. Preserve reproducible artifacts, seeds/configuration, code version, and provenance.

## IP boundary

External materials should explain interfaces, evaluation logic, evidence classes, and results sufficiently for technical review while excluding unnecessary private implementation detail. Repository access should not be required for an initial concept review.
